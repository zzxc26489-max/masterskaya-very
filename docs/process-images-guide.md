# Руководство по изображениям процесса

Для этапов процесса рождения используются только локальные изображения из `assets/images`. Если для этапа нет подходящей фотографии, используйте текстовый блок с описанием, а не внешнее изображение. Новые фотографии следует назвать по этапу (`idea`, `base`, `appearance`, `eyes`, `details`, `story`, `meeting`) и добавить содержательный русский `alt`.
