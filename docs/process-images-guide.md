# Фотографии процесса

Для следующей съёмки нужны: общий план рабочего места, формирование основы, покраска и фактура, создание глаз, изготовление украшений, готовый Житель, упаковка и передача Хранителю. Использовать локальные фотографии с единым тёплым светом; пока отсутствующие кадры представлены тематическими контейнерами без внешних изображений.
