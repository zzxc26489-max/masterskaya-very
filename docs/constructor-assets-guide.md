# Руководство по слоям конструктора

Сцена использует холст 800×800 px; все PNG/WebP-слои должны иметь одинаковый размер и прозрачность. Имена: `body-{species}-{variant}.webp`, `eyes-{tone}.png`, `decoration-{name}.png` в `assets/images/constructor/layers/`. Слои позиционируются `absolute; inset:0` и масштабируются через `aspect-ratio:1`.

Сейчас доступны цельные изображения драконов и лошадей в `assets/images/constructor`; прозрачных слоёв глаз, тела и украшений пока нет. Конструктор честно показывает базовый образ и цветовые swatch-метки, не создавая битых ссылок. Для полноценной композиции нужны отдельные body/eyes/decoration PNG для каждого вида.
