# Codex master task — Мастерская Веры V2

Работать только в ветке `redesign/v2` и продолжать существующий draft PR V2. Не создавать новый PR и не выполнять merge.

## Контекст

Текущий сайт остаётся рабочим. V2 создаётся изолированно в `v2/`, чтобы не наследовать `home.css`, `styles.css`, `v060.css` и `unified.css`. Прочитать перед работой:

- `docs/v2-product-brief.md`;
- `docs/v2-architecture.md`;
- `v2/README.md`.

## Задача первого этапа

1. Проверить созданный V2-прототип в реальном браузере.
2. Не переписывать дизайн с нуля и не добавлять новые визуальные эффекты.
3. Исправить только подтверждённые визуальные или функциональные проблемы.
4. Сделать скриншоты четырёх страниц на ширинах 1440, 768, 390 и 320 px.
5. Проверить:
   - отсутствие горизонтального overflow;
   - корректный crop изображений;
   - читаемость текста поверх hero;
   - меню с клавиатуры, Escape и фокусом;
   - фильтрацию Жителей;
   - отсутствие ошибок консоли и битых ресурсов.

## Затем реализовать второй этап

Создать внутри V2 новый конструктор как отдельную страницу `v2/constructor.html` без копирования старого CSS.

Требования:

- использовать существующие данные вариантов и изображения из `assets/images/constructor/`;
- 4 шага: основа, облик, детали, легенда;
- один крупный предпросмотр без текстовой заглушки поверх изображения;
- mobile: предпросмотр сверху, элементы выбора ниже;
- desktop: предпросмотр слева, управление справа;
- данные состояния хранятся в одном объекте;
- UI рендерится небольшими функциями, без полной перерисовки всей страницы;
- финальная кнопка создаёт резюме и ведёт на `../contacts.html` с query parameters;
- честно объяснить, что результат является направлением индивидуальной работы, а не готовой копией;
- не добавлять стоимость, если она не подтверждена данными;
- не добавлять звук, частицы, cursor glow и перехват всех ссылок.

## Качество

Запустить и зафиксировать результаты:

```bash
node --check v2/assets/js/site.js
node --check v2/assets/js/constructor.js
node scripts/css-audit.mjs
# существующий legacy audit может падать на legacy selectors;
# отдельно добавить/запустить V2-only audit, который обязан проходить.
git diff --check
```

V2-only audit должен проверять:

- V2 не подключает legacy CSS;
- каждый protected V2 component имеет одно base definition;
- нет пустых локальных ссылок;
- все локальные ресурсы существуют;
- нет horizontal overflow в Playwright smoke tests.

## Запрещено

- менять существующие root HTML-страницы на этом этапе;
- удалять legacy CSS или изображения;
- встраивать весь CSS/JS в HTML;
- добавлять framework или npm-зависимости без отдельного обоснования;
- создавать очередные append-only compatibility blocks;
- выполнять merge.

## Итоговый отчёт

Указать:

- commit SHA и remote head SHA;
- URL draft PR;
- список проверенных viewport;
- ссылки/пути к скриншотам;
- найденные и исправленные проблемы;
- оставшиеся ограничения;
- результат V2-only audit.
