# Правила интерфейса

## Навигация и терминология

Утверждённые пункты навигации: **Главная**, **Коллекции**, **Рождение Жителей**, **Хроники Мастерской**, **О Мастерской**, **Свиток для путника**, **Связаться с Мастерской**. Названия не менять без прямого указания владельца проекта.

## Компоненты

- **Кнопки:** основной CTA заметен, но на экране не конкурируют несколько основных кнопок. Текст конкретный и понятный; кнопка не выглядит дешёвой золотой плашкой. Всегда видимый `:focus-visible`, минимальная высота 44 px.
- **Ссылки:** различимы без цвета (подчёркивание, контраст или контекст), имеют понятное назначение и доступное имя.
- **Карточки:** единая иерархия — изображение, название, краткое описание, действие; одинаковые отступы и спокойный hover без сильного подъёма, вращения или свечения.
- **Заголовки:** последовательная иерархия `h1`–`h3`, один смысловой `h1`, адаптивный размер и достаточный контраст.
- **Формы:** явные подписи, подсказки и сообщения об ошибках, корректные `label`, клавиатурный порядок и сохранение введённых данных при ошибке.
- **Навигация:** текущий пункт обозначен программно и визуально; меню доступно с клавиатуры, закрывается Escape и не запирает фокус без необходимости.
- **Модальные окна:** использовать только по делу; `role="dialog"`, заголовок, кнопка закрытия, фокус внутри во время открытия и возврат фокуса инициатору.
- **Мобильное меню:** кнопка с `aria-expanded`/`aria-controls`, область не выходит за экран, ссылки имеют минимум 44 px, закрытие по ссылке, Escape и клику вне меню.
- **Изображения Жителей:** содержательный русский `alt`, корректные пропорции, `loading="lazy"` ниже первого экрана, не искажать и не скрывать важные детали.
- **Состояния:** hover спокойный и дублируется focus; active явно показывает нажатие/выбранность; focus не удалять и не полагаться только на цвет.
- **Клавиатура:** все действия доступны Tab/Shift+Tab/Enter/Space, порядок логичен, нет ловушек фокуса.
- **`prefers-reduced-motion`:** уменьшать переходы, трансформации и автоматическое движение; смысл и доступность сохраняются.
