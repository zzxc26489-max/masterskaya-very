# Мастерская Веры — пробная версия

Статический mobile-first прототип главной страницы.

## Запуск локально

Можно просто открыть `index.html` в браузере.

Для корректной локальной раздачи:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте новый репозиторий.
2. Загрузите в него содержимое этой папки.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/root`.
6. Сохраните настройки.

## Структура

- `index.html` — разметка
- `styles.css` — mobile-first дизайн
- `script.js` — меню и базовые взаимодействия
- `assets/` — изображения

Это демонстрационный концепт. Тексты, персонажи, ссылки, корзина и CMS пока являются заглушками.
