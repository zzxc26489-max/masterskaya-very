# Мастерская Веры — версия 2

Многостраничный mobile-first прототип на реальных фотографиях работ Веры.

## Страницы
- Главная
- Миры и отдельные Миры
- Жители и отдельные карточки Жителей
- Рождение
- Архив
- Хроники
- Хранители
- О Мастерской
- Доставка и упаковка

## Важно
Имена, легенды и описания являются рабочими художественными версиями.
Материалы, размеры, цены, тиражи и фактические биографические сведения нужно подтвердить у Веры.

## Публикация
Загрузите содержимое папки в корень GitHub-репозитория и включите GitHub Pages для ветки main, папка /root.
