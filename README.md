# Мастерская Веры — версия 0.4

Обновлено:
- «Миры» заменены на понятные «Коллекции»;
- коллекции: «Зимние легенды», «Тайны леса», «Древние существа», «Русские сказки»;
- верхняя навигация и поисковая строка на всех страницах;
- «Контакты» заменены на «Связаться с Мастерской»;
- «Путь Хранителя» переименован в «Свиток для путника»;
- на главной появился блок «Новинки Мастерской»;
- под каждым Жителем добавлена кнопка связи;
- тексты приведены к общей концепции: ясная авторская мастерская со сказочной атмосферой.

Откройте `index.html`.
