# Мастерская Веры — версия 0.2

Добавлено:
- отдельный Мир «Мухоморное безумие»;
- 9 реальных фотографий грибных игрушек;
- отдельная Хроника;
- Путь Хранителя;
- страницы ухода и контактов;
- ссылки на новые разделы с Главной, из Миров и Хроник.

Перед публикацией нужно подтвердить материалы, размеры, цены, доступность, доставку, оплату и контакты.


## Оптимизация изображений в версии 0.3
- все JPG/PNG получили адаптивные WebP-копии;
- используются варианты 480, 800, 1280 и 1800 px;
- браузер выбирает подходящий размер через `srcset`;
- изображения ниже первого экрана загружаются через `loading="lazy"`;
- главные изображения страниц получают высокий приоритет;
- добавлены width/height для уменьшения скачков макета.

Тяжёлые исходные JPG/PNG исключены из публикуемой версии. Для хранения оригиналов используйте отдельную резервную папку вне сайта.
