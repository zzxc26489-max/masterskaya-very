# Мастерская Веры V2

Изолированный прототип новой версии сайта. Он не подключает `home.css`, `styles.css`, `v060.css` или `unified.css` и не меняет текущие страницы.

## Страницы

- `v2/index.html` — главная и визуальное направление;
- `v2/worlds.html` — коллекции;
- `v2/residents.html` — архив Жителей с фильтрацией;
- `v2/birth.html` — путь индивидуального заказа и мост к действующему конструктору.

## Принципы

1. Одна система токенов и компонентов.
2. Один базовый блок для каждого компонента; адаптивность только в media queries.
3. Существующие фотографии используются как исходный контент, без растягивания и случайных наложений.
4. Нет случайных частиц, фонового аудио и переходов, блокирующих навигацию.
5. Сначала утверждается вертикальный срез, затем переносится остальной контент и конструктор.
